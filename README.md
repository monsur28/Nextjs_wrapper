# Next.js + Tailwind CSS + Shadcn UI Starter Template

This is a pre-configured starter template designed to save time when starting new Next.js projects. It comes with Tailwind CSS and Shadcn UI already set up and ready to use.

## 🚀 Features

- **[Next.js](https://nextjs.org/)** (App Router)
- **[Tailwind CSS](https://tailwindcss.com/)** for styling
- **[Shadcn UI](https://ui.shadcn.com/)** for customizable components
- **TypeScript** configured
- **ESLint** ready

## 🛠️ Getting Started

### 1. Clone or Copy the Template
Simply copy this folder to start a new project without having to re-install and re-configure everything from scratch.

### 2. Install Dependencies
If you haven't already or if you just copied the folder to a new location, make sure to install the dependencies:

```bash
npm install
```

### 3. Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🧱 Adding Shadcn Components

You can easily add new components using the Shadcn CLI:

```bash
npx shadcn@latest add [component-name]
```
For example, to add a card component:
```bash
npx shadcn@latest add card
```
